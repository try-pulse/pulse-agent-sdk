# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through **Security → Report a vulnerability** on this repository's GitHub page. Include the affected version or commit, a minimal reproduction, and the impact. Remove credentials and personal data from the report.

If private vulnerability reporting is unavailable, ask a repository maintainer through an existing private contact channel for a secure way to share the details. **Do not open a public issue or pull request with vulnerability details.**

The maintainers will review the report and coordinate a fix and disclosure with you. No response-time or supported-version guarantee is implied.
